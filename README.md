# Teacher Toolkit Online

Free browser tools for teachers: merge, split, rotate, number, watermark and shrink PDFs; PDF ↔ pictures; video/audio to MP3; fillable worksheets; QR codes; embed codes; and a "Ready for Schoology?" file check.

**Open it:** https://shaden-edtech.github.io/teacher-toolkit/

Everything runs inside your browser. Files are never uploaded anywhere.
